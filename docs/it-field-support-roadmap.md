# IT Field Support Portfolio Roadmap

These are **proposed exercises**, not completed projects.

## 1. Ethernet cable termination and testing
Perform a permitted Cat5e/Cat6 termination, document T568A/B wire mapping, capture a tester result, and write a service report. Clearly state whether the tester verifies continuity/wire map only or provides standards-based certification.

## 2. Small-office networking (Cisco Packet Tracer)
Build a simulated network with switch, endpoints, IP addressing, DHCP and DNS tests. Include topology, saved .pkt file, test evidence, and troubleshooting notes.

## 3. Windows support lab
Practice local account administration, driver diagnostics, connectivity troubleshooting, Windows event logs, and basic PowerShell. Document initial symptoms, commands, changes, and final verification.

## 4. POS and peripheral support simulation
Draft a permitted troubleshooting exercise for a disconnected receipt printer or barcode scanner. Separate assumed symptoms from actually observed test results.

## Portfolio acceptance criteria
- Reproducible setup instructions
- Evidence showing actual results
- Clear distinction between simulation and professional work
- Concise scope, steps, verification, and limitations
- No credentials, private customer data, or unauthorized testing

Use [the lab template](../templates/lab-report-template.md) or [field-service template](../templates/field-service-work-order.md).
